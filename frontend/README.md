# Neighborrow frontend

Интерфейс по Figma на React / TypeScript / Vinext. Он запускается как самостоятельное Node-приложение и обращается к Django API. Демоданных и фиктивного входа нет.

## Локальный запуск

Нужны Node.js 22.13+ и pnpm версии, указанной в `package.json`.

```powershell
pnpm install --frozen-lockfile
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
npm.cmd run dev
```

Откройте `http://localhost:5173`. В другом терминале должен работать Django на `http://127.0.0.1:8000`. Адрес API задаётся в `.env.local`:

```dotenv
NEXT_PUBLIC_NEIGHBORROW_API_URL=http://127.0.0.1:8000/api/v1
```

После изменения URL перезапустите фронтенд. `CORS_ALLOWED_ORIGINS` бэкенда должен включать origin фронтенда (по умолчанию `http://localhost:5173` разрешён).

Production-сборка и локальная проверка её сервера:

```powershell
npm.cmd run build
npm.cmd run start
```

`npm.cmd run start` запускает Vinext на Node; для внешнего размещения задайте публичный HTTPS-адрес Django API при сборке и разрешите origin сайта в Django.

## Подключённые функции

- Регистрация и вход; ошибки сервера выводятся пользователю.
- JWT в памяти вкладки, автоматическое обновление токенов, выход.
- Лента, поиск, категории, сортировка и страницы результатов.
- Создание, просмотр, изменение и удаление своих объявлений, изменение доступности.
- Подбор встречных объявлений через backend.
- Контакты для вошедших пользователей; отклики без чата.
- Профиль, адрес, смена ЖК по коду нового комплекса, смена пароля, удаление аккаунта с подтверждением.
- Настоящая личная активность вместо демонстрационных строк.

Данные хранятся в базе. Сессия входа пока находится только в памяти: после обновления страницы нужно войти снова; объявления и профиль остаются в базе. Пароли и JWT не записываются в localStorage.

Карта и загрузка файлов ещё не реализованы. Для фотографии объявления можно указать HTTP(S)-ссылку.

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

`tests/api-client.test.mjs` проверяет обновление токенов, выход, ошибки и отмену запросов. `tests/api-integration.mjs` выполняет сценарий с двумя пользователями через этот же API-клиент и настоящий Django сервер. Запуск из корня объединённого проекта описан в его README.
